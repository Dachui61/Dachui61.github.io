# 5. 默认深色

- 状态：已接受
- 日期：2026-11-22
- 相关决定：6

## 上下文

参考站 AIHero.Dev 是**浅色默认** + 深色可选（`next-themes`，
`defaultTheme: 'system'`）。

但本站展示的 Vitals 界面本身就是深色的——菜单栏读数、悬浮面板、每核
曲线，全都是在深色底上做的。这是已经存在的产品事实。

## 决策

本站**默认深色**，浅色作为可选项。用户可以选三态：深色、浅色、跟随系统，
用 `localStorage` 记住，切换前用内联脚本在首帧前应用，避免闪白。

```css
:root, .dark { --bg: #0b0b0b; --fg: #f4f3f1; /* … */ }
[data-theme='light'] { --bg: #fbfbfc; --fg: #14161a; /* … */ }
```

## 后果

- **三态而不是两态**，和 Vitals 面板底部的切换器是同一套词汇
  （跟随系统 / 浅色 / 深色）。全站统一。
- 与参考站**不一致**。这是有意的：如果本站要和 AIHero 长得一样，就没
  有理由做两个站。
- 深色下所有 token 都要重新调，不是把浅色反相。琥珀色强调色在深色下
  直接可用，在浅色下要压暗到 `#b8860b` 才够对比度。
- 主题切换是纯 CSS 变量替换，Tailwind 的 `@theme inline` 让工具类直接
  引用实时变量，所以切换不需要重新构建。

## 备选方案（被否掉的）

| 方案 | 否掉原因 |
|---|---|
| 浅色默认，和参考站一致 | 与本站展示的产品自相矛盾 |
| 跟随系统默认 | 系统多半是浅色，等于回到浅色默认 |
| 只有深色，不给开关 | 有人白天在强光下看屏幕；不给选项不如不给默认 |
